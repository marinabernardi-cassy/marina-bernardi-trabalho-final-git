# Sangue & Veludo

**Nome:** Marina Bernardi  
**Data:** 23/09/2026

## Sobre o projeto

O Sangue & Veludo é um site de uma loja de moda gótica. A ideia do projeto é mostrar alguns produtos da loja e permitir que o usuário coloque os produtos em um carrinho.

## O que foi usado

- HTML para montar a página;
- CSS para deixar o site organizado e bonito;
- JavaScript para fazer o carrinho funcionar;
- LocalStorage para guardar os produtos adicionados.

## Como funciona

Na página principal aparecem os produtos, com nome, imagem e preço. Ao clicar em **Adicionar ao carrinho**, o produto é colocado no carrinho.

O número de produtos também aparece no botão do carrinho e é atualizado conforme os produtos são adicionados.

## Como abrir o projeto

O projeto pode ser executado pelo XAMPP.

1. Coloque a pasta do projeto dentro da pasta `htdocs`.
2. Abra o XAMPP.
3. Inicie o Apache.
4. Abra o projeto pelo navegador usando `localhost`.

## Objetivo

O objetivo foi criar uma loja virtual simples e praticar HTML, CSS e JavaScript, principalmente a criação e o funcionamento de um carrinho de compras.
